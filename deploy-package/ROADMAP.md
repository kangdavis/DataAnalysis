# 투자자의 회상 완성도 개선 로드맵

## 1단계: 안정적인 MVP

- 로그인, 회원가입, 로그아웃
- 사용자별 투자 회고 저장
- 공개 회고와 비공개 회고 분리
- 분류 3종 고정: 기업분석, 산업분석, 매매일지
- 회고 쓰기 화면 정리: 제목, 본문, 리스크와 체크포인트, 발행 설정
- 서버 입력값 검증과 기본값 정리

## 2단계: 블로그 완성도

- 글 상세 URL 추가
- 공개 글 목록 페이지와 상세 페이지 분리
- 대표 이미지 또는 썸네일
- 글 임시저장과 자동저장
- 작성 중 이탈 방지
- 글 발행 전 최종 확인 화면

## 3단계: 운영 관리

- 관리자 계정과 관리자 화면
- 사용자 관리
- 신고 또는 비공개 처리
- 데이터 백업과 복원
- 운영 로그

## 4단계: 배포 품질

- 영구 데이터 저장소 연결
- HTTPS 환경에서 Secure 쿠키 적용
- 도메인 연결
- 배포 환경 변수 정리
- 정기 백업
