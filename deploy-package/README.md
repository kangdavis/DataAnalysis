# 투자자의 회상

로그인 기반 다중 사용자 투자 회고 아카이브입니다.

## 실행

```bash
npm start
```

또는:

```bash
node server.js
```

실행 후 `http://localhost:4173`으로 접속하세요.

## 기능

- 회원가입
- 로그인 / 로그아웃
- 사용자별 투자 회고 작성, 수정, 삭제
- 공개 회고와 비공개 회고 분리
- 공개 회고 전체 조회
- 로그인 화면에서 별도 회원가입 페이지로 이동
- 회고형 글쓰기 화면: 큰 제목 입력, 편집 툴바, 본문 작성, 우측 발행 설정
- 분류 3종 고정: 기업분석, 산업분석, 매매일지
- 파일 기반 데이터 저장: `data/db.json`

## 배포

정적 호스팅만으로는 로그인과 다중 사용자 저장이 동작하지 않습니다. Render, Railway, Fly.io, VPS처럼 Node 서버를 실행할 수 있는 환경에 배포하세요.

운영에서는 `data/db.json`이 사라지지 않도록 영구 디스크를 연결하고 정기적으로 백업하는 것을 권장합니다.

공개 도메인 연결 절차는 `DEPLOY.md`를 참고하세요.
